# 洞洞板接線表（平面版：兩板並排）

洞洞板 23×18 孔（58.4×45.7 mm），孔位 (c, r)：c 為欄 1–23（左→右）、r 為列 1–18（下→上，正面俯視）。

## 零件位置（正面）

| 零件 | 孔位 | 備註 |
|---|---|---|
| U1 nice!nano | c2–c13 × r2（P0.06 側）、r8（RAW 側） | USB-C 朝左緣；遠離 USB 的一端（天線側）右方淨空 |
| U2 BlackPill | c3–c22 × r17（3.3/G/5V…B12 排）、r11（VB…3.3/G/5V 排） | 轉 180°，USB-C 朝右緣 |
| U3 DMC2038LVT（SOT-23-6 轉接板） | r6：G1 c19、S2 c20、G2 c21；r3：D1 c19、S1 c20、D2 c21 | 互補 MOSFET（N+P） |
| R1 | c19 r1 ↔ c22 r1 | 跨在 D1 與 D2 之間 |
| 電池 | 反面，貼在 BlackPill 正下方（Kapton 膠帶絕緣） | 假設 30×25×5 mm |

## 接線（全部走反面，點對點）

| 線號 | 顏色 | 起點 | 終點 | 用途 |
|---|---|---|---|---|
| W1 | 紅 | BAT + | U1 RAW (c2,r8) | 電池正極 |
| W2 | 黑 | BAT − | U1 GND (c3,r8) | 電池負極（改接 GND） |
| W3 | 黃 | U2 PA9 (c17,r17) | U1 P0.08 (c3,r2) | UART：BlackPill TX → nRF RX |
| W4 | 黑 | U1 GND (c3,r8) | U2 G (c4,r17) | 兩板共地（新增） |
| W5 | 紅 | U2 5V (c22,r11) | U3 G2 (c21,r6) | BlackPill 5V → G2 |
| W6 | 黑 | U2 G (c21,r11) | U3 S2 (c20,r6) | S2 → GND |
| W7 | 黑 | U3 S2 (c20,r6) | U3 S1 (c20,r3) | S1 → GND |
| W8 | 紅 | U3 G1 (c19,r6) | U3 D2 (c21,r3) | G1 ↔ D2 相連（焊在轉接板上） |
| W9 | 紅 | U3 D2 (c21,r3) | R1 (c22,r1) | D2 → R1 |
| W10 | 橘 | U3 D1 (c19,r3) | R1 (c19,r1) | D1 → R1 |
